Project Overview

For this project, I built a procedural dungeon generation system that can handle any width or height. I also made sure the layout doesn’t create loops, so there’s always one clear path through the dungeon.

I added a player system that can move through the dungeon using different pathfinding methods like A*, Dijkstra, and Unity’s NavMesh, so I could compare how each one behaves.

For tile placement, I used Marching Squares and Flood Fill. This helped make the corners look smoother and made it easier to swap out different tile assets.

I also used Unity Gizmos a lot to visualize what was happening during generation, which made it much easier to debug and improve the system step by step.

Development

I started by working on the dungeon generation system and made sure it didn’t create loops, so there was always a clear and valid path through the dungeon.

After that, I implemented some core algorithms like Breadth-First Search (BFS), Depth-First Search (DFS), and Flood Fill to help control how the dungeon gets generated.

I also used Marching Squares to figure out how tiles should connect visually, which made the asset system more flexible and modular.

Finally, I worked on pathfinding by implementing A* and Dijkstra’s algorithm, and compared how they performed in different types of dungeon layouts.

Throughout the whole process, I used gizmos a lot to visualize what was happening and to help debug the generation in real time.
