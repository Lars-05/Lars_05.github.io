Project Overview

In this project, I developed multiple custom shaders using HLSL and Shader Graph in Unity.

These included visual effects such as dissolve, hologram, and intersection shaders, as well as more technical shaders involving custom lighting calculations and real-time normal manipulation.

I also built a procedural tree generation system that dynamically constructs meshes and UVs based on adjustable parameters, allowing flexible and scalable tree creation directly in-engine.

Development

I started by exploring Unity’s Shader Graph and gradually moved into writing custom HLSL shaders for more control over rendering behavior.

From there, I implemented multiple visual effects such as dissolve transitions, holographic distortion, and surface intersection effects.

I also worked on custom lighting models, using vector math (dot and cross products) to calculate normals and simulate more physically accurate shading.

Finally, I built a procedural tree system that generates geometry, assigns UVs, and adapts its shape based on parameters like height, branching, and randomness.

What I Learned

  • Manipulating textures and color data in real time
  • Understanding normals, UVs, and mesh construction
  • Using dot and cross products for lighting calculations
  • Working with coordinate spaces and transformation matrices
